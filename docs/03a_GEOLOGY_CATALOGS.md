# Геология: справочные каталоги

Стартовые списки для [03_GEOLOGY.md](./03_GEOLOGY.md). Материя уже живёт в `assets/matter/matter.xml` (ключи без префиксов, модуль `matter`, [06_BLOCKS](./06_BLOCKS.md)), и он источник истины; `assets/geology/` хранит JSON геологических каталогов (`province_columns.json`). Этот файл остаётся описанием замысла.

**Про числа.** Плотности, твёрдости и размеры здесь ориентировочные («типичное значение»), они нужны, чтобы исполнитель не начинал с пустого места. Перед записью в данные каждое значение проверить по источнику (раздел 19 основного документа) и поставить `source`. Если значение остаётся игровым, `provenance: gameplay`.

Обозначения: `ρ` плотность, `H` твёрдость по Моосу (для пород «класс копания» от 1 до 5: 1 мягкий грунт, 2 слабая порода, 3 средняя, 4 прочная, 5 очень прочная), «≥ …» нижняя граница.

## 7. Типовые разрезы провинций (для `ProvinceTemplate`)

Снизу вверх; примеси и вероятности хранятся в данных.

| Провинция | Разрез |
|---|---|
| Кратон (щит) | ТТГ-гнейс (тоналит, ортогнейс) и зеленокаменные пояса (коматиит, базальт, BIF, граувакка) → граниты и пегматиты → (редко) платформенный чехол: кварцевый песчаник, шейл, известняк |
| Платформа | фундамент кратона → терригенный низ (конгломерат, песчаник) → шейл → известняк и доломит → эвапориты (гипс, соль) → красноцветы → (по эпохе) угольные пласты |
| Осадочный бассейн | фундамент → красноцветы → эвапориты → материнские шейлы и мергели → песчаные коллекторы → известняк → терригенный верх |
| Коллизионный ороген | метапелиты (филлит → сланец → гнейс), мрамор и кварцит, зелёные сланцы и амфиболиты, офиолитовые пластины (серпентинит, габбро, подушечный базальт), гранитные плутоны с пегматитами и скарнами |
| Вулканическая дуга | фундамент → андезиты и дациты с туфами → порфировые штоки и дайки → риолитовые покровы и игнимбриты, эпитермальные зоны |
| Рифт | фундамент → красноцветы → базальты → озёрные шейлы и эвапориты → карбонатитовые пробки |
| LIP | фундамент → стопка покровных базальтов (каждый поток 5–30 м) с туфами и красными прослоями → силлы долерита и расслоённые интрузии |
| Пассивная окраина | фундамент → красноцветы и эвапориты рифта → карбонатная платформа и дельтовые пески → материнские шейлы |
| Океаническая кора | перидотит → габбро → дайковый комплекс (долерит) → подушечные базальты → пелагические осадки (кремнистые, меловые, железо-марганцевые корки) |

## 8. Метаморфизм

Региональный по протолиту (ступени растут с глубиной и стрессом):

| Протолит | Ряд |
|---|---|
| аргиллит, шейл | слабая: сланец кровельный → филлит → слюдяной сланец → гнейс → мигматит; в алюмосиликатных породах зоны кианита, ставролита, силлиманита |
| песчаник | кварцит |
| известняк, доломит | мрамор |
| базальт, габбро | зелёный сланец → амфиболит → гранулит; при высоких давлениях голубой сланец → эклогит |
| гранит | ортогнейс |
| перидотит | серпентинит → тальковый сланец |
| граувакка | гнейс, зелёный сланец |

Контактовый: известняк → мрамор, скарн; шейл → роговик; песчаник → кварцит; базальт → роговик; эвапориты → ангидрит.

## 9. Выветривание по климату

| Климат | Профиль |
|---|---|
| Влажные тропики | сапролит 10–40 м → железистая кора (латерит) → бокситы на глинозёмистых и никелевые латериты на ультраосновных; интенсивное окисление сульфидов, госсан |
| Умеренный | глины и суглинки 1–5 м, бурые почвы, карбонатные зоны |
| Аридный | кальклет, гипсовые коры, силькрет; соль в понижениях; окисленные зоны Cu |
| Холодный | ледниковый тилл, мороз, мерзлота, лёсс; карст слабый |
| Горы | скальные обнажения, осыпи |

Эти таблицы стартовые; уточнять по данным провинций и климата планеты.
