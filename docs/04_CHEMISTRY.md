# Химия: основа (C0)

Общая база для геологии, переработки и промышленности. Библиотека `InfinitesiaChemistry` (`src/domains/natural/chemistry/`) не зависит ни от raylib, ни от остального проекта; геология, мир и будущая промышленность линкуются с ней. Видение: «MASTER» раздел 11, «EXTREME» документ 10. Здесь только то, что уже сделано, и что отложено.

## Состав

| Что | Файл | Назначение |
|---|---|---|
| `Element`, `AllElements`, `GetElement`, `FindElement` | `Element.h/.cpp` | таблица всех 118 элементов: Z, символ, английское имя, атомная масса, группа, период, блок, категория |
| `Composition` | `Composition.h/.cpp` | число атомов каждого элемента на формульную единицу: разбор формулы, молярная масса, массовые доли |
| `Blend` | `Composition.h` | смесь конечных членов по молям (твёрдые растворы) |
| `ElementMassFractions`, `Mix` | `Composition.h` | массовые доли элементов в материале и смешивание по массам (руда = доля × минералы + остаток × порода) |
| `Reaction` | `Reaction.h/.cpp` | уравнение с коэффициентами, проверка сохранения атомов по каждому элементу, массы сторон |

Тесты: `tests/ChemistryTests.cpp` (цель `ChemistryTests`).

## Решения

- **ID элемента это атомный номер.** Он и есть постоянный числовой ID для сохранений и реестров, не переиспользуется.
- **Масса.** Условные значения IUPAC (сокращённые, как в таблице NIST «Atomic Weights and Isotopic Compositions»). Для элементов с интервалом стандартного веса (H, Li, B, C, N, O, Mg, Si, S, Cl, Ar, Br, Tl, Pb) взято условное значение. Для элементов без стабильных изотопов (34 штуки: Tc, Pm, Po–Ac, Np–Og) `hasStandardWeight = false`, а масса равна массовому числу самого долгоживущего изотопа; у Z ≥ 95 NIST стандартного веса не даёт, эти числа взяты как общепринятые. Менять их можно только по справочнику.
- **Группы.** Лантаноиды La–Yb и актиноиды Ac–No имеют `group = 0`, Lu и Lr отнесены к группе 3 (d-блок), He в s-блоке. Это соглашение, а не наука: `category` (лантаноид, актиноид и т.д.) задаётся отдельно.
- **Только справочное ядро.** В таблице нет плотности, температур плавления, степеней окисления, кларков и аффинности: это содержимое реестров, которое накладывается на элемент по Z (JSON, этап G1). Русские названия тоже данные, не код.
- **Формулы.** Один формат: ASCII, элементы с числами, скобки `()` и `[]`, дробные индексы для твёрдых растворов и нестехиометрии (`(Mg1.8Fe0.2)SiO4`, `Fe0.95S`), гидраты через `*` или `·` (`CaSO4*2H2O`). Нет зарядов и списков «или» (`(F,OH)`): формула описывает один конкретный состав; вариации задаются конечными членами через `Blend` или типичным дробным составом. Ошибки разбора сообщают позицию.
- **Детерминизм.** Записи в `Composition` всегда отсортированы по Z, слияние одинаковых элементов в порядке Z, никакого общего состояния.
- **Баланс.** `Reaction::Imbalances` считает изменение числа атомов каждого элемента с относительным допуском; у сбалансированного уравнения массы сторон совпадают.

## Пример

```cpp
using namespace Infinitesia::Chemistry;

Composition chalcopyrite = Composition::Parse("CuFeS2");
double cuShare = chalcopyrite.MassFraction(FindElement("Cu")->atomicNumber); // 0.346

// Ore block: 25 % pyrite, 75 % quartz host rock, by mass.
MassPart parts[] = { { Composition::Parse("FeS2").MassFractions(), 0.25 },
                     { Composition::Parse("SiO2").MassFractions(), 0.75 } };
ElementMassFractions ore = Mix(parts);

bool ok = Reaction::Parse("4 FeS2 + 11 O2 -> 2 Fe2O3 + 8 SO2").IsBalanced();
```

## Что отложено

Осознанно не делается, пока нет потребителя:

- изотопы и радиоактивный распад (`IsotopeSystem`): нужны датированию и радиогенному теплу, этап G8/G9;
- ионы, заряды и баланс зарядов, водная химия, pH, комплексы;
- термодинамика (энтальпия, энтропия, энергия Гиббса), равновесие, кинетика, катализаторы, условия реакций;
- фазовые переходы, фазовые диаграммы;
- реестр соединений и реакций с ID, состоянием вещества, свойствами (`Compound`): появится вместе с каталогом минералов в G1 как обёртка над `Composition`;
- единицы измерения как типы: пока везде г/моль и доли.

Появятся вместе с переработкой и промышленностью («EXTREME» документы 10, 19, 20), а точкой подключения служат `Composition` и `Reaction`.

## Что нужно геологии (G1)

1. Реестр минералов: `formula` из каталога (`03a`) разбирается `Composition::Parse`; `mass` и `elementMassFractions` считаются, а не хранятся вручную.
2. Состав породы: `Mix` по модальному составу, содержание любого элемента в блоке тем же `Mix` (раздел 14 из `03_GEOLOGY.md`).
3. Тесты реестра: молярная масса минерала совпадает со справочной в пределах 0,1 %; суммы массовых долей равны 1.
4. Формулы каталога с вариативным составом (`(Mg,Fe)₂SiO₄`, `plagioclase`, `hornblende`, `zeolite`, `limonite`) заменить типичным дробным составом, например `(Mg1.8Fe0.2)SiO4`. Список вариативных минералов нужно отметить в данных (`solidSolution`).
